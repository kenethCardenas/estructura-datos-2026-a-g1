#  Árbol Binario con las letras M, F, T, A, H, R, Z

## Diagrama del árbol binario

(M)
/
(F) (T)
/ \ /
(A) (H) (R) (Z)


## Identificación de elementos

| Elemento       | Nodos                          |
|----------------|--------------------------------|
| **Raíz**       | M                              |
| **Hojas**      | A, H, R, Z                     |
| **Altura**     | 2                              |

## Explicación del árbol

- **Raíz**: La letra `M` es el nodo superior del que descienden todos los demás.
- **Hojas**: `A`, `H`, `R` y `Z` son las hojas porque no tienen hijos.
- **Altura**: La altura del árbol es **2**, ya que el camino más largo desde la raíz hasta una hoja tiene **2 aristas** (por ejemplo: M → F → A).

## Reglas aplicadas

- Cada nodo tiene **como máximo dos hijos** (árbol binario).
- Se respetó el orden de inserción dado: M, F, T, A, H, R, Z.
- El árbol no es necesariamente de búsqueda; es solo un árbol binario general.

## Importancia del ejercicio

Comprender la estructura de un árbol binario (raíz, nodos internos, hojas y altura) es fundamental para luego abordar temas más avanzados como:
- Árboles binarios de búsqueda (ABB)
- Recorridos (inorden, preorden, postorden)
- Balanceo de árboles
