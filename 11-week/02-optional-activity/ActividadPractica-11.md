#  Árbol Organizacional de una Empresa

## Diagrama del árbol

(Gerente General)
│
┌──────────────┴──────────────┐
│ │
(Depto A) (Depto B)
│ │ │ │
│ │ │ │
(Emp A1) (Emp A2) (Emp B1) (Emp B2)

## Identificación de elementos

| Elemento       | Nodos                                 |
|----------------|---------------------------------------|
| **Raíz**       | Gerente General                       |
| **Nodos internos** | Gerente General, Depto A, Depto B  |
| **Hojas**      | Emp A1, Emp A2, Emp B1, Emp B2        |

## Altura del árbol

- **Altura**: 2  
  (Camino más largo: Gerente General → Depto A → Emp A1 → **2 aristas**)

## Explicación breve

El árbol cumple exactamente con la estructura solicitada:
- **1 raíz** (Gerente General)
- **2 nodos internos hijos** (Departamentos A y B)
- **4 hojas** (2 empleados por departamento)
- **Altura = 2**

Es un árbol general donde cada nodo puede tener múltiples hijos. Esta jerarquía organizacional es un ejemplo clásico de árbol en estructuras de datos, base para conceptos más avanzados como árboles binarios y árboles de búsqueda.
